COLTESS: Curves of Light from TESS.

A lightweight Python package for extracting light curves from TESS (Transiting Exoplanet Survey Satellite) Full Frame Images (FFIs).

Main entry points:

  • create_catalog() — build a Gaia DR3 catalog around a target.
  • process_images_parallel() — download and analyze TESS FFIs in parallel.
  • process_local_images_parallel() — analyze local FITS files in parallel.
  • analyze_image() — analyze a single local FITS image.
  • load_photometry_data() — load the light curve from the output CSV.
  • compute_periodogram() — Lomb-Scargle periodogram with FAP.

123    def process_fits(self, fits_path: str, catalog: List[tuple]) -> Optional[Table]:
124        """
125        Process a single TESS FITS image and perform photometry on catalog sources.
126
127        Parameters
128        ----------
129        fits_path : str
130            Path to the TESS FFI FITS file.
131        catalog : list of tuple
132            Catalog entries as `(ra, dec, source_id)`.
133
134        Returns
135        -------
136        astropy.table.Table or None
137            Table containing photometric measurements and metadata for all
138            detected catalog sources in the frame, or None if no sources fall
139            within the image footprint.
140        """
141        with fits.open(fits_path) as hdul:
142            image = hdul[1].data
143            header = hdul[1].header
144            wcs = WCS(header)
145
146            # Determine effective gain for Poisson noise term
147            bunit = header.get("BUNIT", "").strip().lower()
148            if "e-/s" in bunit or "e- /s" in bunit:
149                self.epadu = header.get("EXPTIME", header.get("TINT", 200.0))
150            else:
151                self.epadu = 5.22
152
153        # Filter objects in frame
154        objects_in_frame = []
155        for ra, dec, obj_id in catalog:
156            try:
157                x, y = SkyCoord(ra, dec, unit=u.deg).to_pixel(wcs)
158                if 0 <= x < image.shape[1] and 0 <= y < image.shape[0]:
159                    objects_in_frame.append((ra, dec, obj_id, x, y))
160            except Exception:
161                continue
162
163        if not objects_in_frame:
164            # print("no object in frame")
165            return None
166
167        # Extract positions
168        positions = [(pos[3], pos[4]) for pos in objects_in_frame]
169
170        # Perform photometry
171        result_table = self._perform_aperture_photometry(image, positions)
172
173        # Add metadata
174        result_table["RA"] = [pos[0] for pos in objects_in_frame]
175        result_table["DEC"] = [pos[1] for pos in objects_in_frame]
176        result_table["ID"] = [pos[2] for pos in objects_in_frame]
177        result_table["DATE-OBS"] = header.get("DATE-OBS", "")
178
179        return result_table

181    def _perform_aperture_photometry(
182        self, image: np.ndarray, positions: List[tuple]
183    ) -> Table:
184        """
185        Perform aperture photometry at specified pixel positions.
186
187        Parameters
188        ----------
189        image : numpy.ndarray
190            2D image array extracted from the FITS file.
191        positions : list of tuple
192            Initial `(x, y)` pixel coordinates for photometry.
193
194        Returns
195        -------
196        astropy.table.Table
197            Table containing fluxes, magnitudes, and magnitude uncertainties
198            for all successfully measured sources.
199        """
200        # Centroid refinement
201        x_init, y_init = zip(*positions)
202        x_cent, y_cent = centroid_sources(
203            image, x_init, y_init, box_size=3, centroid_func=centroid_com
204        )
205
206        # Remove failed centroids
207        valid = ~np.isnan(x_cent)
208        positions = [(x_cent[i], y_cent[i]) for i in range(len(x_cent)) if valid[i]]
209
210        # Aperture definitions
211        aperture = CircularAperture(positions, r=self.aperture_radius)
212        annulus = CircularAnnulus(
213            positions, r_in=self.annulus_inner, r_out=self.annulus_outer
214        )
215
216        # Photometry
217        phot_table = aperture_photometry(image, [aperture, annulus])
218
219        # Background subtraction
220        bkg_mean = phot_table["aperture_sum_1"] / annulus.area
221        bkg_sum = bkg_mean * aperture.area
222        final_flux = phot_table["aperture_sum_0"] - bkg_sum
223
224        # Calculate magnitudes
225        magnitudes = self.zeropoint - 2.5 * np.log10(np.abs(final_flux))
226
227        # Error estimation
228        _, _, std = sigma_clipped_stats(image, sigma=3.0)
229
230        # Flux uncertainty (in electrons)
231        flux_uncertainty = np.sqrt(
232            np.abs(final_flux) / self.epadu
233            + aperture.area * std**2
234            + aperture.area * std**2 / annulus.area
235        )
236
237        # Magnitude uncertainty
238        mag_error = 1.0857 * flux_uncertainty / np.abs(final_flux)
239
240        # Create output table
241        result = Table()
242        result["flux"] = final_flux
243        result["mag"] = magnitudes
244        result["mag_err"] = mag_error
245        result["flux_err"] = flux_uncertainty
246
247        return result

308                    flush=True,
309                )

311
312            # Keep only if it contains the star
313            lambda_tau_row = result[idx : idx + 1]
314
315            return lambda_tau_row

132def compute_periodogram(
133    times: np.ndarray,
134    fluxes: np.ndarray,
135    flux_errors: Optional[np.ndarray] = None,
136    min_period: float = 0.1,
137    max_period: float = 10.0,
138    oversampling: float = 5.0,
139) -> dict:
140    """Compute Lomb-Scargle periodogram with weighted fitting and FAP.
141
142    Parameters
143    ----------
144    times : np.ndarray
145        Observation times (e.g., Julian Date).
146    fluxes : np.ndarray
147        Measured fluxes.
148    flux_errors : np.ndarray, optional
149        1-sigma flux uncertainties. If provided, passed to LombScargle
150        as `dy` for weighted periodogram (generalized LS).
151    min_period : float, optional
152        Minimum period to search (days).
153    max_period : float, optional
154        Maximum period to search (days).
155    oversampling : float, optional
156        Oversampling factor relative to the frequency resolution 1/T.
157        Default 5 follows VanderPlas (2018) recommendation.
158
159    Returns
160    -------
161    dict
162        Dictionary containing:
163        - 'periods': array of periods (days)
164        - 'power': array of periodogram power
165        - 'frequency': array of frequencies (1/days)
166        - 'peak_indices': list of peak indices sorted by power
167        - 'primary_period': best period or None
168        - 'primary_period_uncertainty': 1-sigma uncertainty or None
169        - 'primary_fap': False alarm probability (Baluev 2008) or None
170        - 'secondary_period': second best period or None
171    """
172    times = np.asarray(times)
173    fluxes = np.asarray(fluxes)
174
175    mask = ~np.isnan(times) & ~np.isnan(fluxes)
176    if flux_errors is not None:
177        flux_errors = np.asarray(flux_errors)
178        mask &= ~np.isnan(flux_errors)
179
180    times = times[mask]
181    fluxes = fluxes[mask]
182    if flux_errors is not None:
183        flux_errors = flux_errors[mask]
184
185    if len(times) < 3:
186        return {
187            "periods": np.array([]),
188            "power": np.array([]),
189            "frequency": np.array([]),
190            "peak_indices": [],
191            "primary_period": None,
192            "primary_period_uncertainty": None,
193            "primary_fap": None,
194            "secondary_period": None,
195        }
196
197    baseline = times.max() - times.min()
198    df = 1.0 / baseline / oversampling
199    f_min = 1.0 / max_period
200    f_max = 1.0 / min_period
201    frequency = np.arange(f_min, f_max, df)
202    periods = 1.0 / frequency
203
204    ls = LombScargle(times, fluxes, dy=flux_errors, normalization="standard")
205    power = ls.power(frequency)
206
207    # Peak finding with prominence and distance thresholds
208    power_std = np.std(power)
209    min_distance = max(1, int(1.0 / df))  # at least one independent resolution element
210    peaks, _ = find_peaks(power, prominence=3.0 * power_std, distance=min_distance)
211    sorted_peaks = sorted(peaks, key=lambda x: power[x], reverse=True)
212
213    results = {
214        "periods": periods,
215        "power": power,
216        "frequency": frequency,
217        "peak_indices": sorted_peaks,
218        "primary_period": None,
219        "primary_period_uncertainty": None,
220        "primary_fap": None,
221        "secondary_period": None,
222    }
223
224    if len(sorted_peaks) >= 1:
225        primary_idx = sorted_peaks[0]
226        results["primary_period"] = float(periods[primary_idx])
227        results["primary_period_uncertainty"] = estimate_period_uncertainty(
228            frequency, power, primary_idx, baseline
229        )
230        # Baluev (2008) analytic FAP
231        fap = ls.false_alarm_probability(
232            power[primary_idx],
233            method="baluev",
234            minimum_frequency=frequency.min(),
235            maximum_frequency=frequency.max(),
236        )
237        results["primary_fap"] = float(fap)
238
239    if len(sorted_peaks) >= 2:
240        results["secondary_period"] = float(periods[sorted_peaks[1]])
241
242    return results

Analyze FITS images already stored locally, in parallel.

This function performs photometry over all FITS files in a directory without downloading anything. One row per detection is appended to a single output CSV file, with the FITS header SECTOR and the local file path (in the CURL column) as metadata.

Parameters

fits_dir : str Directory containing the FITS images. catalog_file : str Path to a Gaia catalog CSV. star : StarData Target star information. output_file : str or None, optional Path of the single CSV file that photometry rows are appended to. Defaults to <star name>.csv. max_workers : int or None, optional Number of parallel worker processes. Defaults to the number of available CPU cores. keep_images_dir : str or None, optional Directory where FITS images in which the star was detected are copied. If None, no images are kept. pattern : str, optional Glob pattern used to select files inside fits_dir. Defaults to "*.fits".

Notes

  • Images whose path is already stored in the output file are skipped, so re-running resumes automatically. The deduplication keys on the exact path string; different path spellings for the same file will not be recognized as duplicates.
  • Rows are appended under an exclusive file lock.
  • Pressing Ctrl+C terminates all workers immediately and exits with status code 130.
